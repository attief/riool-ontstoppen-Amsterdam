# Ontstoppingsdienst 24-7 Rapport plugin

## Installatie
1. Plaats de map `ontstoppingsdienst-rapport-plugin` in `wp-content/plugins/`.
2. Activeer de plugin in WordPress.
3. Voeg shortcode `[ontstoppingsdienst_rapport]` toe aan een pagina.

## Wat deze plugin doet
- Rendered een uitgebreide rapport-pagina met Tailwind styling.
- Toont een vaste inhoudsopgave met smooth-scroll gedrag.
- Laadt externe assets (Tailwind, Font Awesome, Google Fonts) alleen bij shortcode-render.
